# BMS Monitor — frontend

React / строгий TypeScript. Живой экран батареи получает снимок через HTTP и обновления через Mercure. Production — только статические файлы, без Node/Vite/Docker.

Репозиторий: `git@github.com:lexwm/bms_monitor_forntend.git`.

- [Сборка, поставка и маршруты для DevOps](docs/deployment.md).
- [Снимок OpenAPI backend](contracts/openapi.json). Это копия, не самостоятельный источник контракта.
- [Правила разработки](AGENTS.md).

Локальная совместная разработка: `./bin/up` и `./bin/check` из корня workspace BMS_Monitor. Frontend может быть собран отдельно: все необходимые файлы входят в его репозиторий. Node 22, зависимости строго из `package-lock.json`; инструкции сборки находятся в deployment.md.

При изменении API скопировать `contracts/openapi.json` из backend в `contracts/openapi.json` этого репозитория (в общем workspace `./bin/sync-contract`), затем выполнить `npm run generate:api` через локальный контейнер. `npm run check:generated` проверяет соответствие типов/схем снимку. Общая проверка workspace дополнительно проверяет идентичность снимка backend. Generated-файлы не редактировать вручную.

## Дашборд

Единственный язык интерфейса — украинский, включая подсказки, ошибки и подписи для экранного диктора. Числа и даты форматируются по `uk-UA`, время — Киев. Текст интерфейса на другом языке считается ошибкой.

Состояние батареи определяется знаком исходного тока по подтверждённому владельцем правилу: положительный — «Заряджання», отрицательный — «Розряджання», ровно ноль — «Від мережі / без заряджання». Порог 1 А не применяется: даже +0,04 А означает зарядку, а −0,04 А — разрядку. Подпись о сети — согласованное обозначение нулевого тока этой установки, а не показание отдельного датчика сети. При отсутствии показания тока, устаревших данных или ошибке связи состояние объясняется отдельно, без выдачи сохранённого режима за текущий.

Утверждённый графитовый макет с золотом/серебром и индикатором 3B («Дуга под стеклом»). На узком экране карточки перестраиваются в одну колонку, ток и мощность остаются рядом. Меню скрывается; анимации учитывают системную настройку уменьшения движения.

Текущие значения приходят через существующую подписку Mercure. Главный экран показывает только текущие показания; графики и полнота истории находятся на странице «Історія» (`#history`). У неё один переключатель периода для всех вкладок: 10 минут (по умолчанию), 1, 12 или 24 часа, 30 дней, квартал либо год. Вкладки: «Огляд» (`#history`) — ровно пять графиков на общей оси времени: мощность, ток, заряд, напряжение батареи, температуры всех датчиков; «Комірки» (`#history/cells`, `#history/cells/N`, N = 1…8) — восемь линий напряжения ячеек на одном графике (выбранная выделена, остальные приглушены) и график разброса, мВ; «Енергія» (`#history/energy`); «Події» (`#history/events`). Ячейка на главном экране — ссылка на историю этой ячейки. Ряды получает `GET /api/v1/battery/history/series?range=…&set=overview|cells`; границы последних трёх и двенадцати календарных месяцев рассчитывает backend.

Курсор графиков общий для вкладки: мышь, касание или клавиатура (график выбирается клавишей Tab, ← и → сдвигают курсор на одну точку или интервал, Home/End — к краям). Каждый график для экранного диктора — ползунок (`slider`) с названием графика, текстовым описанием и текущим значением, равным строке над графиками. Значения под курсором всех графиков вкладки сразу показываются этой строкой; диктор озвучивает их только при движении курсора касанием или клавишами, а не при наведении мышью и не при обновлении данных. Смена периода или вкладки сбрасывает курсор. Пояснения (пропуски, среднее и мин–макс, частичный интервал, «готується») показаны один раз над графиками вкладки; у графика остаётся только ключ его линий. Подписи оси значений округляются по масштабу: без знаков после запятой от 100, один знак от 10, два от 1, три ниже. Каждый отрезок линии рисуется одним элементом SVG, поэтому число узлов не растёт с числом точек.

«Енергія» — «зареєстрована енергія» по календарным дням Киева (`GET /api/v1/battery/energy/daily`), кВт·год с двумя знаками, доля покрытия каждого дня (неполный день с покрытием от 99 до 100 % — «понад 99 %», а не «100 %»). Для периодов короче 30 дней показываются 30 дней. Подписи: «немає даних» (без столбика, а не нулевой столбик), «готується» (прошедший неподготовленный день; при ненулевом покрытии — со столбиком уже подготовленной части), «частково» (день начала подготовленной истории), «сьогодні, станом на …» (важнее, чем «частково»). Постоянное предупреждение: «Струми, менші приблизно за 2,5 А, можуть реєструватися як 0, тому значення можуть бути заниженими». «Події» — журнал (`GET /api/v1/battery/events`) с постоянной пометкой «За даними батареї; тлумачення сигналів захисту не підтверджено»; формулировку действия интерфейс строит по виду события, отмечает событие после промежутка без измерений, старые страницы загружаются кнопкой.

Колокольчик в шапке загорается, если сервер сообщает начало важного эпизода (`latest_important_at`), более новое, чем отметка «просмотрено» этого браузера. Открытие журнала сохраняет значение сервера как отметку (localStorage; если хранилище недоступно — в памяти вкладки); пустое значение отметку не стирает. Состояние передаётся и текстом для экранного диктора.

На главном экране под ячейками и температурами — строки «За 24 год»: наименьшее и наибольшее напряжение среди всех ячеек и наибольший разброс, наименьшая и наибольшая температура среди всех датчиков. Прочерк — значений нет; «готується» — хотя бы один интервал периода ещё не подготовлен. Эти значения обновляются только после подготовки сводной истории и отстают от свежих измерений примерно до 5 минут. Кнопка «Оновити знімок» находится рядом с блоком «Про дані та час вимірювань» и в блоке «Повнота історії» страницы истории. Длинные периоды показывают среднее и приглушённые границы минимума/максимума. Частично заполненный интервал показывается отдельно; ожидающий подготовки интервал не считается пропуском измерений или нулём. Пока часть истории не подготовлена, общий процент полноты неизвестен; объём подготовленной части указан отдельно.

`useTelemetry` остаётся единственным владельцем подписки Mercure и раздаёт сигналы: «новое измерение» (`telemetry.updated.v1`), «изменилась подготовленная история» (рост `aggregate_revision` в `history.updated.v1`), «восстановление» и «видимость». Каждый потребитель сам владеет запросом, пределом частоты и отменой. Пределы: колокольчик — `events?limit=1` только по подготовленной истории, не чаще раза в 60 секунд; главный экран — `series?range=10m` по измерениям не чаще раза в 15 секунд, `series?range=24h&set=overview` и `&set=cells` только по подготовленной истории не чаще раза в 60 секунд каждый; страница истории — один запрос активной вкладки и периода (15 секунд для 10 минут/1 часа, 60 секунд для сводных периодов), «Енергія» — по подготовленной истории не чаще раза в 60 секунд, журнал — по действию пользователя. Обычно главный экран делает около 4–5 запросов в минуту; пока backend готовит новые сводки (каждый проход меняет ревизию), — до ~7 в минуту. Один отложенный запрос сохраняет последний сигнал; без сигналов запросов нет. Выбор периода загружает его сразу, не переподключая канал и текущие показатели. Скрытая вкладка приостанавливает всех потребителей; при возвращении каждый делает один немедленный запрос. При загрузке или ошибке сохраняется подписанный предыдущий снимок; выбранная кнопка обозначает запрошенный период. Задержавшийся ответ прежнего выбора не заменяет последний выбор. Смена готового снимка плавно сменяет линии и оси за 220 мс без изменения размеров графика; настройка уменьшения движения отключает переход. Отсутствующее значение показателя не равно нулю: интервал, который ещё готовится, показан приглушённым фоном и подписью «готується», а не пропуском измерений.

«Налаштування батареї» — отдельная страница (`#configuration`, пункт главного меню), а не блок под дашбордом; серверных маршрутов она не требует. Значения разложены по вкладкам и двум колонкам, пороги защиты сведены в таблицы «порог / восстановление / задержка». Группировка задаётся кодами полей в `src/configurationLayout.ts`; всё, что туда не попало (неизвестные коды и повторы полей), остаётся на вкладке «Службові» вместе с источником и исходными байтами. Пустые вкладки не показываются. На вкладке «Знімки» — список сохранённых снимков настроек (по 20, следующая порция — кнопкой «Завантажити ще»; подпись «Показано знімків: N» напоминает, что всё ниже считается только по загруженным снимкам). Выбранный снимок сравнивается с ближайшим более старым: изменением считается разница значений поля, которое в обоих снимках расшифровано; поле, отсутствующее или нерасшифрованное хотя бы в одном из них, выводится отдельно как «немає даних для порівняння», неполные снимки помечены. Таблица износа по загруженным снимкам показывает дату, «Вивчена ємність», число циклов и долю от «Номінальна ємність» того же снимка; если какого-то значения нет — прочерк. Подробности снимков загружаются лениво, не больше двух запросов одновременно.

В подробной истории линии не соединяются через gaps, невалидные записи, отсутствующие значения показателя, смену boot_id и промежутки больше 10 секунд. В сводной истории линия соединяет только полностью покрытые непрерывные интервалы одного показателя при совпадении загрузки источника и расстоянии между граничными измерениями не более 10 секунд. По сводным данным нельзя восстановить точные границы коротких пропусков. Пропуски отображаются нейтральной штриховкой; отсутствие отдельного показателя — разрывом его линии. Нулевые измерения остаются нулями, неизвестные — прочерками. Полнота истории берётся из API и относится ко всем измерениям, а не к непрерывности работы батареи. Состояние данных и их возраст показаны в шапке, отдельного блока пояснений под ней нет; при обрыве канала обновлений там же появляется пометка «Канал оновлень відновлюється». В меню три пункта: «Огляд», «Історія» и «Налаштування батареї». Значок сайта и манифест лежат в `public/assets/` (SVG с прозрачным фоном и PNG 180/192/512, полученные из него).

Под ячейками в одном ряду стоят компактные блоки: температуры, расчётное время до полного заряда или разряда и счётчик циклов зарядки из показаний батареи (`battery.cycles`; при отсутствии значения — прочерк). Расчётное время (`src/estimate.ts`) — грубая линейная оценка: при разряде остаток ёмкости делится на ток, при заряде — недостающая до заявленной ёмкость. Средний ток за 10 минут используется, только если показания свежие, покрытие окна не меньше 300 секунд, все значения тока в окне одного знака, без нулей и пропусков, последний запрос окна был успешным и окно заканчивается не раньше чем за 30 секунд до последнего измерения (подпись «за середнім струмом за 10 хв»); иначе — текущий ток («за поточним струмом»). Нулевой текущий ток даёт прочерк и пояснение «Струм дорівнює нулю (малі струми можуть не реєструватися)». Показываются длительность и «≈ до ГГ:ХХ» по Киеву (с датой, если не сегодня). При устаревших данных или отсутствии нужных значений — прочерк с пояснением. Восемь горизонтальных ячеек расположены в два ряда по четыре, напряжение показано внутри с тремя знаками после запятой; заполнение показывает напряжение, не процент заряда; температурные полосы — шкалу без оценки безопасных порогов.
